## Code 노드 언어 함정 (B4)

- 무슨 일이 있었나:
  Code 노드의 JavaScript 코드를 Python으로 실행하려고 하면서 실행 오류가 발생했다.

- 원인:
  n8n Code 노드의 실행 언어와 코드 문법이 일치하지 않았기 때문이다.

- 어떻게 해결했나:
  Code 노드의 언어를 JavaScript로 맞추고, JavaScript 문법으로 코드를 실행해 정상적으로 판정 결과를 확인했다.

## AI 활용 구분

- AI 에게 맡긴 일:
  Python/n8n 코드 작성과 오류 원인 확인, API 테스트 명령어 작성, 증적 및 제출문 구성에 대한 도움을 받았다.

- 내가 직접 판단한 일:
  실제 실행 결과와 캡처를 직접 확인하고, 메신저 연결 상태와 게시판 저장 결과를 확인했다. 또한 제출 체크리스트에 맞춰 필요한 증적을 직접 선택했다.

- AI 제안을 따르지 않은 일(또는 없었던 이유):
  환경변수 방식으로 n8n 비밀값을 분리하는 방법을 검토했지만, 이번 과제의 E2 요구사항이 Export JSON의 토큰을 `<...>`로 지우는 것이므로 실제 n8n Docker 환경을 불필요하게 변경하지 않고 제출용 Export에서 비밀값을 제거하는 방식을 선택했다.

## 막혔던 것 · 해결

1. n8n Webhook 호출 시 GET으로 JSON Body를 보내려고 해 오류가 발생했다.
   → POST 방식으로 변경해 정상적으로 JSON을 전송했다.

2. Telegram 전송 과정에서 일시적으로 연결 거부 오류가 발생했다.
   → 네트워크 연결 상태를 확인하고 HTTPS 요청이 정상 응답하는 것을 확인한 뒤 다시 실행해 정상 전송했다.

3. Code 노드에서 실행 언어와 코드 문법이 맞지 않아 오류가 발생했다.
   → JavaScript로 언어를 맞춘 뒤 다시 실행해 정상적인 severity/decision 결과를 확인했다.
